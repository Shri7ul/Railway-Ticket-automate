# 🚆 Bangladesh Railway Auto Ticket Bot

এই টুল দিয়ে সহজেই বাংলাদেশ রেলওয়ের টিকেট বুকিং করা যায়।  
আপনাকে শুধু **`.exe` ফাইল রান করতে হবে** → তারপর নিজে ইনপুট দেবেন (From, To, Date, Train, Class ইত্যাদি)।  
কোনো কোড জানা লাগবে না।  

---

## ✨ Features
- ✅ Auto Login (আপনার মোবাইল নম্বর + পাসওয়ার্ড দিয়ে)  
- ✅ Station নির্বাচন (From & To)  
- ✅ তারিখ ও সময় নির্বাচন  
- ✅ নির্দিষ্ট Train + Class এর টিকেট সিলেক্ট  
- ✅ Auto Seat Selection (1–4 seats)  
- ✅ Toast Notification → সফল হলে নোটিফিকেশন দেখাবে  

---

## 📥 Installation

1. [Release Section][(../../releases)](https://github.com/Shri7ul/Railway-Ticket-automate/commit/d75f608cf2cf77c9f8077f9a12501e1517fa2add) থেকে **Railway-Bot.zip** ডাউনলোড করুন  
2. Zip ফাইল Extract করুন  
3. ভেতরে পাবেন:  
   - `app.exe` → Main Bot  
   - `chromedriver.exe` → Browser driver  

---

## ▶️ Usage

1. `app.exe` ডাবল ক্লিক করুন  
2. আপনার ইনপুট দিন (যেমন নিচে দেখানো হলো):  

Enter Your Phone Number: 01XXXXXXXXX
Enter Your Password: ********
From (e.g. Dhaka): Dhaka
To (e.g. Bogura): Bogura
Train Name (e.g. RANGPUR EXPRESS): RANGPUR EXPRESS
Seat Class (e.g. S_CHAIR): S_CHAIR
How many seat you need max 4?: 2
Date? (e.g. 4): 6
Schedule Time? (HH:MM Format): 21:45


3. ঠিক সময় আসলে Bot নিজে থেকেই বুকিং শুরু করবে 🚀
